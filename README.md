# Student Grade Management System

## Project Overview
A Python-based application for managing student academic records, marks, grades and performance reports.

## Features
- Add, update and delete student records
- Manage marks across multiple subjects
- Calculate total marks and percentages
- Assign letter grades and GPA
- Generate class performance statistics
- Search student records
- Generate individual report cards
- Export student records to CSV
- Save student data using JSON

## Technologies Used
- Python
- JSON
- CSV
- File Handling

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
python main.py
```
